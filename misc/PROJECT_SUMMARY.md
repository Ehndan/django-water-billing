## 🚀 Getting Started

### 1️⃣ Install
```bash
pip install -r requirements.txt
```

### 2️⃣ Setup
```bash
python manage.py migrate
python manage.py createsuperuser
```

### 3️⃣ Run
```bash
python manage.py runserver
```

### 4️⃣ Access
```
http://localhost:8000/api/
```

**That's it! ✅**
